Foundations

Tokens first. Components consume roles, never hex.

Semantic slots stay the same in every theme, so a component written once resolves in all four. Income and expense keep the financial convention of green and red on purpose, and they never carry meaning alone: a sign, a label or a glyph always travels with the colour.

Primitives

One element, every state, on the same page.

A primitive is done when its six microstates are drawn and it survives the ugly cases: a forty-character name, a negative balance, a list of one. These are the pieces everything else is composed from.

The signature. Currency and cents recede so the integer carries the eye. One face at every size; statement sizes go to weight 600 with tighter tracking. Negative is a true minus, never parentheses.

Conventions

The rules this page was written under.

The full set, with lint configuration, lives in the proposal document beside this file. These are the ones that shape every line above.

Cascade order is the contract

@layer reset, tokens, base, layouts,
       primitives, components, pages, utilities;
  • Every rule lives in a layer. Only the reduced-motion override sits outside, so it beats everything without !important.
  • A later layer always wins. Specificity inside a layer stays at one class, one attribute.

Tokens in three tiers

--p-indigo-600   primitive, tokens file only
--accent         semantic, what components use
--_bg            component-local, underscore
  • No hex outside @layer tokens. Stylelint enforces it.
  • Four themes redefine semantic slots only. Components never mention a theme.

Naming

.t-money .t-money__cents .t-money--xl
[data-valence] [data-health] [data-variant]
.l-stack .l-cluster   .u-num   .is-loading
  • t- primitives and components, l- layouts, u- utilities, is- transient state.
  • Meaning goes in a data attribute, never a second class.

Numbers are typeset, not printed

  • tabular-nums on every figure, date and count.
  • Money is one primitive at four sizes. Sign is a true minus.
  • Colour never carries meaning alone: sign, label or glyph travels with it.
  • Charts share one scale; text wears text tokens.

Six states or it is not done

  • default · hover · focus-visible · active · disabled · loading, drawn on the specimen page.
  • Empty, error and worst-case content states beside the happy path.
  • Reduced motion respected; focus ring is a token.

The seam

import type { BudgetVariance } from "../api/budgets";
fetch("/api/v1/x")  →  fixtures/x.json  (dev)
  • Components take payloads, never fetch. The server's exported types are the types.
  • Money is a number in currency units, 2dp, as the backend contract decides. Money formats it; nothing else touches it.
  • Due days, ring percent and budget status come from the server. The client never re-derives them.
