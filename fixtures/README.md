# Fixtures

Generated by `npm run fixtures` (scripts/fixtures.ts). Do not hand-edit --
change the generator and re-run instead. Deterministic: a fixed seed and a
fixed "today" (2026-09-02) mean two runs produce byte-identical output.

## States

- **populated/** -- a household with two members, four linked institutions
  (two separate items both named "Chase" -- everything here is keyed on
  `itemId`, never on institution name), eight accounts, ~14 months of
  transaction history, five recurring streams, four budget limits (one
  `danger`, one `caution`), three goals, and ~90 irregularly-spaced
  balance snapshots. The default "everything is working, there's a real
  household behind it" state.
- **empty/** -- a fresh install: one household member, nothing linked yet.
  `liquidity.json`'s `updatedAt` is `null` (no sync has ever run, which is
  a different state from "synced, and everything is zero"), `items.json` is
  `[]`, `summary.json`'s `byCategory` is `[]` with every total at 0, and
  every other list/array endpoint is empty. `sync-runs-latest.json` is
  `null` -- there has never been a sync.
- **error/** -- every endpoint file is the standard error envelope
  (`{ "error": { "code", "message", "details"? } }`, see src/web/errors.ts)
  instead of its normal payload, with a spread of real error codes across
  the endpoint list: `VALIDATION_FAILED`, `UNAUTHENTICATED`, `RATE_LIMITED`,
  `FEATURE_DISABLED`, `UPSTREAM_ERROR`, `INTERNAL`.
- **midsync/** -- identical to populated/, except `sync-runs-latest.json`
  has `status: "running"` with a partially-filled `items` array, and the
  Chase (Grace) item in `items.json` has `needsReauth: true` with
  `status: "LOGIN_REQUIRED"`.

## Endpoints

Each state directory has one file per API endpoint, named after its path
with `/` replaced by `-` (e.g. `/transactions/range` ->
`transactions-range.json`).

One of these -- `sync-runs-latest.json` --
don't have a real endpoint/type in `src/` yet (the former is referenced by
a query schema but not wired up; the latter's `SyncRun` model lands in a
later wave). Both are built to the same conventions as everything else here
and documented at their construction site in scripts/fixtures.ts; treat them
as a proposal to reconcile against the real shape once it exists.
